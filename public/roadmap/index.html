Specification Status

Current & upcoming work

The roadmap reflects the Foundation's active specification tracks and their current maturity. Status designations follow a defined lifecycle: stable specifications are suitable for production implementations; draft specifications are open for comment but subject to change; planned items are scoped but not yet in active drafting.

Roadmap priorities are set by the Technical Committee in consultation with Working Groups and the broader membership. Community members may influence prioritisation through the RFC process.

Stable
CPD-1.0 — Canonical Payment Descriptor Stable

Defines the canonical wire format for payment intent representation. Foundation layer for all higher-level protocols.

View specification →
CPP-1.0 — CashPack Protocol Stable

End-to-end payment packaging protocol built on CPD-1.0. Covers encoding, routing hints, and merchant-facing business models.

View specification →
MPC-1.0 — Disposable Keys Stable

Multi-party computation specification for single-use signing key derivation. Reduces custodial risk in delegated payment flows.

View specification →
SSF-001 — Stablecoin Stack Stable

Architecture and core concepts for stablecoin-based settlement. Defines issuance, redemption, and transfer interfaces.

View specification →
In Draft
SSF-002 — Wallet-Gateway Interface Draft

Defines the standard interface between end-user wallet software and gateway infrastructure. Open for community comment.

View draft →
Planned
SSF-003 — Compliance & Screening Interface Planned

Standard interface for pluggable AML/CFT screening modules, enabling compliance without embedding vendor-specific logic into the core stack.

SSF-004 — Cross-Chain Bridge Protocol Planned

Defines atomic swap and bridge message formats for interoperability between heterogeneous ledger environments.

SSF-005 — Custody & Delegation Model Planned

Formalises delegation chains, co-signing arrangements, and custody transfer protocols for institutional deployments.

SSF-006–009 Planned

Further tracks under scoping by the Stablecoin Stack Working Group. Scope and prioritisation subject to community RFC process.
